# 平台口径与合规

## 一、完播三段（本包的设计依据）

抖音完播考核按三段计，权重 **3 : 5 : 2**：

| 段位 | 帧区间（30fps） | 权重 | 设计动作 |
|---|---|---|---|
| 首屏停留 | 0 到 90 | 3 | 结果加断言，不出现工具名与自我介绍，首帧有主体 |
| 核心停留 | 300 到 600 | 5 | 递进拆解加一处微型钩子，情绪二次爬升 |
| 看到结尾 | 末场 | 2 | 观点句或人设句收束，收藏暗示，CTA 停留不低于 60 帧 |

**口径来源与风险**：平台未公开算法权重，3:5:2 属行业复盘口径（由使用者提供）。
落地前请用自己账号后台的“平均播放时长 / 3 秒完播率 / 完播率”复核，权重以实测为准。
本包把它作为**结构优先级**使用，不作为平台官方事实对外引用。

**收藏率**：行业共识是收藏权重高于单纯完播。收藏的前提是“这条以后用得上”，
结尾必须有可被截图的观点句或人设句，只留一句“加粉丝群”等于放弃这一档。

## 二、画面与安全区

| 平台 | 比例 | 画布 | 安全区（上 / 下 / 左 / 右） |
|---|---|---|---|
| 抖音视频 | 9:16 | 1080×1920 | 100 / 200 / 60 / 60 |
| 小红书视频 | 3:4 | 1080×1440 | 100 / 120 / 60 / 60 |
| 小红书封面 | 3:4 | 1080×1440 | 上下各留 10%，独立设计，不从视频裁帧 |
| 视频号 | 9:16 | 1080×1920 | 100 / 200 / 60 / 60，核心内容收进中央安全带 |

抖音可读区实际为 920 × 1620，字幕按此排版。
字号：`hook` 60 到 80，`h1` 48 到 60，`body` 36 到 44，`caption` 28 到 32。
单屏关键文字不超过 15 字，每行不超过 16 字，最多 2 行。

## 三、小红书差异

| 项目 | 抖音 | 小红书 |
|---|---|---|
| 比例 | 9:16 | 3:4 为主，1:1 次之 |
| 观点句位置 | 回扣段（27 到 34 秒） | 封面文案或正文第一段 |
| 收藏暗示 | 结尾口播 | 正文末尾一句 |
| 粉丝群 | 视频内口播 | 评论区首评，正文不写群 |
| 帧表 | 完整 `scriptTimeline` | 不输出帧表，只出封面、标题、正文、首评 |
| 标题 | 由钩子句承担 | 20 字内，第二人称加结果承诺 |
| 正文 | 无 | 300 到 500 字，短段落 |

同一份内容换平台必须重排版面，改个宽度就发，字号与留白一定塌。

## 四、合规五条

1. **极限词**：最、第一、唯一、绝对、百分百、100%。口播出现一个就可能被判违规，`validate.py` 的 D3 会抓。
2. **虚假承诺**：保证、必定、立刻、稳赚。有效果必须有出处，否则改定性表述。
3. **站外导流**：微信、VX、加我、私聊、扫码。改说“主页”“平台内私信”“粉丝群”。
4. **粉丝群路径**：可以说“主页粉丝群”，不要说“加我微信进群”。粉丝群不是违禁词，配合导流话术会被限流。
5. **事实**：数字进 `claims.source`，项目归属标 `role_tag`，主导、负责、参与不混用；不泄露前雇主敏感信息，不用客户未授权名称。

猎头视角另加一条：不贬低候选人，对话访谈里提问方不能只当“托”。

## 五、发布后看哪三个数

隔 24 小时看：3 秒完播率、平均播放时长、收藏率。

- 3 秒完播低于 40%：改钩子与首帧，不动中段。
- 平均播放时长低于总长的 40%：中段钩子没落位，或功能点又写回并列了。
- 收藏率低于 1%：观点句不够狠，或结尾没给收藏理由。

一次只改一处，改完等 24 小时再看，不要一天连改三版。
